glTF 를 STL 로 변환

glTF 파일을 STL 로 바꿉니다. STL 은 거의 모든 3D프린터와 슬라이서가 읽는 표준 형식입니다. 파일은 서버로 올라가지 않고 이 브라우저 안에서만 처리됩니다.

3D 프린팅은 유어팀에서 합리적이고 전문적으로 진행하세요

보내 주신 모델 파일을 출력 전에 먼저 검토합니다. 구멍 난 곳, 너무 얇은 벽, 받침이 필요한 곳 같은 문제점을 짚어 피드백을 드리고, 바로잡은 모델로 출력까지 진행합니다.

  • 모델 파일 문제점 검토 · 피드백 (출력 전에)
  • 고칠 곳이 많으면 3D 모델링 수정 · 제작까지 (모델링 + 출력 8만 원부터)
  • FDM · SLA 장비 41대, 보통 3~7일 안에 출고
  • 견적은 실제로 쓰인 재료 무게로 산정

    glTF 를 STL 로 바꾸는 방법

    1. 위 상자에 glTF 파일을 끌어 놓습니다. 여러 파일을 한 번에 골라도 됩니다.
    2. '바꿀 형식'이 STL 인지 확인합니다. glTF 에서 온 파일은 미터 단위라 mm 로 자동으로 바꿉니다.
    3. 부품이 여럿이면 목록에서 받을 부품만 남기고, 한 파일로 받을지 부품마다 따로 받을지 고릅니다.
    4. '변환해서 내려받기'를 누릅니다. 큰 파일은 ZIP 압축이나 분할을 고를 수 있습니다.

    glTF 와 STL 의 차이

    항목glTFSTL
    주로 쓰는 곳웹 · AR (GLB 의 글자판)3D프린터 · 슬라이서 표준
    단위미터 (m)기록 안 됨 (보통 mm 로 읽음)
    색 · 재질색 · 텍스처 (별도 파일일 수 있음)없음
    여러 부품노드마다 여러 메시이진은 한 덩어리, 문자는 여러 개(solid) 가능
    용량중간 (데이터를 별도 .bin 에 두기도 함)큼 (삼각형마다 꼭짓점을 따로 적음)

    바꿀 때 알아 둘 점

    • glTF 안에 물체가 여러 개면 STL 로 바꿀 때 한 덩어리로 합쳐집니다. 부품을 나눠 두려면 '부품마다 따로'를 고르거나 3MF 로 받으세요.
    • glTF · GLB 는 미터 단위라 mm 로 1000배 키우고, 위쪽 방향(Y 위)을 3D프린팅 기준(Z 위)으로 돌려 맞춥니다.
    • glTF 의 색 · 재질 · 텍스처는 STL 로 옮겨지지 않습니다.
    • 이진 STL 이 기본입니다. 문자 STL 이 필요하면 'STL (문자)'를 고르세요. 문자 STL 은 용량이 4~5배 큽니다.

    지원 형식

    많이 쓰는 3D프린팅 · 웹 형식은 이 페이지에서 바로 바꿉니다. CAD · 게임 · 건축 · 스캔 형식은 파일을 보내 주시면 변환할 수 있는지 확인해 드립니다.

    분류형식이 페이지에서
    3D프린팅 · 메시STL, OBJ, 3MF, PLY, OFF, AMF바로 보기 · 바로 변환
    웹 · ARGLB, glTF바로 보기 · 바로 변환 (glTF 는 데이터가 파일 안에 든 것만)
    산업용 CADSTEP, STP, IGES, IGS, SAT, X_T, 3DM, DXF, DWG파일을 보내 주시면 확인
    CAD 원본SLDPRT, SLDASM, IPT, IAM, F3D, FCSTD, PRT, PAR파일을 보내 주시면 확인 (원본 프로그램에서 STEP · STL 로 내보내는 것이 가장 정확합니다)
    게임 · 애니메이션FBX, DAE, ABC, USD, USDZ, BLEND, MAX, MA, MB, C4D파일을 보내 주시면 확인
    건축 · BIMSKP, IFC, RVT, PLN, VWX파일을 보내 주시면 확인
    3D 스캔 · 점 데이터E57, LAS, LAZ, PCD, XYZ, PTS파일을 보내 주시면 확인 (점 데이터는 면을 만드는 작업이 필요합니다)
    프린터 출력 파일GCODE, BGCODE, 3MF(프로젝트), CTB, PHOTON, SL1이미 특정 프린터용으로 잘린 파일이라 다른 형식으로 되돌릴 수 없습니다. 원본 모델을 보내 주세요.

    자주 묻는 질문

    Q1glTF 를 STL 로 바꾸면 무엇이 달라지나요?

    glTF 안에 물체가 여러 개면 STL 로 바꿀 때 한 덩어리로 합쳐집니다. 부품을 나눠 두려면 '부품마다 따로'를 고르거나 3MF 로 받으세요. glTF · GLB 는 미터 단위라 mm 로 1000배 키우고, 위쪽 방향(Y 위)을 3D프린팅 기준(Z 위)으로 돌려 맞춥니다. glTF 의 색 · 재질 · 텍스처는 STL 로 옮겨지지 않습니다. 이진 STL 이 기본입니다. 문자 STL 이 필요하면 'STL (문자)'를 고르세요. 문자 STL 은 용량이 4~5배 큽니다.

    Q23D 파일 용량이 너무 커서 메일 · 카톡으로 못 보내요.

    '분할'에서 10 · 25 · 50 · 100 MB 를 고르면 3D 파일을 ZIP 으로 압축한 뒤 정한 크기로 나눠(분할 압축) 내려받습니다. 받는 사람은 반디집 · 7-Zip 으로 첫 조각(.001)을 열면 됩니다. STL 을 3MF 로 바꾸기만 해도 용량이 보통 크게 줄어듭니다.

    Q3파일이 서버에 올라가나요?

    아닙니다. 변환과 미리보기는 모두 지금 쓰시는 브라우저 안에서 처리되고, 파일은 어디에도 전송되지 않습니다. 회사 도면처럼 밖으로 내보내기 어려운 파일도 안심하고 쓰실 수 있습니다.

    Q4파일 하나에 부품이 여러 개 들어 있으면 어떻게 되나요?

    3MF 의 여러 물체, OBJ 의 물체 · 그룹(o · g), GLB · glTF 의 노드, 문자 STL 의 여러 solid 를 부품으로 나눠 목록에 보여 줍니다. 부품마다 색이 다르고, 체크를 끄면 화면과 내려받기에서 빠집니다. 내려받을 때는 한 파일에 모두 담거나 부품마다 따로 받을 수 있습니다. 한 덩어리로 저장된 STL 안에 떨어진 조각이 여럿이면 '떨어진 조각으로 나누기' 단추가 나타납니다.

    Q5무료인가요? 용량 제한이 있나요?

    무료이고 회원가입도 필요 없습니다. 용량 제한은 따로 없지만, 브라우저 메모리 안에서 처리하므로 수백 MB 를 넘는 파일은 컴퓨터 사양에 따라 느리거나 멈출 수 있습니다.

    Q6변환하면 색이나 재질도 옮겨지나요?

    아니요. 이 도구는 형상(모양)만 옮깁니다. 색 · 재질 · 텍스처는 빠집니다. 3D프린팅에는 형상만 있으면 충분합니다.

    Q7'열린 모서리'가 있다고 나오면 어떻게 하나요?

    모델에 구멍이 있거나 면이 맞물리지 않은 곳이 있다는 뜻입니다. 이대로는 출력이 잘못될 수 있습니다. 파일을 보내 주시면 수정해서 출력해 드립니다.

    Q8분할 파일은 어떻게 합치나요?

    같은 폴더에 모든 조각(.001, .002 …)을 둔 뒤, 반디집이나 7-Zip 에서 첫 조각(.001)을 열고 압축을 풀면 원래 파일이 나옵니다.

    Q9STEP · SolidWorks · Fusion 360 파일도 되나요?

    이 페이지에서는 아직 안 됩니다. 파일을 보내 주시면 변환과 출력을 함께 도와드립니다. 원본 프로그램이 있으시면 '내보내기'에서 STL 이나 3MF 로 저장하는 것이 가장 정확합니다.

    Q10변환한 파일을 실제로 출력할 수 있나요?

    네. 유어팀이 출력 전에 모델 파일의 문제점(구멍, 얇은 벽, 받침이 필요한 곳 등)을 검토해 피드백을 드리고, FDM · SLA 장비 41대로 출력해 드립니다. 견적은 실제로 쓰인 재료 무게로 산정하고, 보통 3~7일 안에 출고합니다. 변환기에서 연 모델의 크기와 부피는 견적 문의서에 자동으로 채워집니다.
