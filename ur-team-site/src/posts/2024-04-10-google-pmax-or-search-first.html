구글 광고를 처음 시작하는 작은 가게라면 검색 캠페인으로 시작하고, 전환 추적이 자리 잡은 뒤에 실적 최대화 캠페인을 더하는 순서가 무난합니다. 실적 최대화 캠페인은 검색 · 유튜브 · 디스플레이 · 지메일 · 지도 같은 여러 광고 자리에 한 번에 보이는 대신, 목표로 삼을 전환과 이미지 · 영상 같은 재료가 있어야 제대로 움직입니다. 검색 캠페인은 손님이 직접 찾는 단어에만 보여서 결과를 읽기 쉽습니다.

핵심 요약

  • 검색 캠페인은 광고주가 고른 키워드를 검색한 사람에게 보이는 광고입니다.
  • 실적 최대화 캠페인은 목표를 정하면 구글이 여러 광고 자리에서 전환할 사람을 찾는 캠페인입니다.
  • 구글은 실적 최대화 캠페인을 키워드 기반 검색 캠페인을 보완하는 수단으로 안내합니다.
  • 검색어가 검색 캠페인의 일치검색 키워드와 같으면 검색 캠페인이 먼저 게재됩니다.

두 캠페인은 무엇이 다른가요?

검색 캠페인은 광고주가 키워드를 고르고, 그 단어를 검색한 사람에게 글자 광고를 보여 줍니다. 무엇을 검색한 사람에게 얼마를 썼는지가 분명히 보이고, 원하지 않는 검색어는 빼면서 다듬을 수 있습니다.

실적 최대화 캠페인은 목표 중심입니다. 판매나 문의 같은 목표와 이미지 · 문구 · 영상 같은 재료를 넣으면, 구글이 여러 광고 자리 가운데 전환이 날 만한 곳을 골라 보여 줍니다. 입찰은 스마트 자동 입찰로 이뤄집니다. 손이 덜 가는 대신, 어디에 어떻게 보였는지를 광고주가 하나하나 정하지는 않습니다.

실적 최대화 캠페인이 잘 맞는 경우는 언제인가요?

구글 고객센터는 다음과 같은 경우 실적 최대화 캠페인을 권합니다.

  • 온라인 판매나 문의처럼 구체적인 전환 목표가 있을 때
  • 광고가 보일 곳을 제한하지 않고 성과를 키우고 싶을 때
  • 한 캠페인으로 구글의 여러 광고 채널에 닿고 싶을 때
  • 키워드 기반 검색 캠페인보다 더 넓게 손님을 찾고 싶을 때

반대로 손님이 주로 지역명과 업종으로 검색해 찾아오는 가게라면, 검색 캠페인만으로도 필요한 손님 대부분을 만날 수 있습니다. 이런 경우 실적 최대화 캠페인은 서두를 이유가 없습니다.

공통점은 전환 목표입니다. 문의나 구매가 정확히 세어지지 않으면 구글은 무엇을 늘려야 할지 알 수 없습니다. 그래서 전환 추적이 없거나 아직 불안정하다면 실적 최대화 캠페인부터 여는 것은 이릅니다. 자동 입찰이 전환 기록에 기대는 원리는 자동 입찰로 넘어가는 시점 글에 정리해 두었습니다.

왜 검색 캠페인부터 시작하나요?

첫째, 배우는 것이 많습니다. 검색 캠페인을 몇 주 돌리면 손님이 실제로 어떤 단어로 찾는지, 어떤 문구에 반응하는지가 보입니다. 이 내용은 나중에 실적 최대화 캠페인에 넣을 문구와 재료를 만드는 데 그대로 쓰입니다.

둘째, 전환 기록이 쌓입니다. 검색 캠페인으로 문의가 꾸준히 들어오면 전환 추적이 맞는지 확인할 수 있고, 그 기록이 실적 최대화 캠페인의 출발점이 됩니다.

검색 캠페인은 원하지 않는 검색어를 제외하면서 비용이 새는 곳을 직접 막을 수 있습니다. 처음 몇 주 동안 이 작업을 해 두면 어떤 손님이 우리에게 맞는지 감이 생기고, 실적 최대화 캠페인을 열었을 때 결과가 좋은지 나쁜지를 판단할 기준도 생깁니다. 비교할 기준 없이 실적 최대화 캠페인만 돌리면 지금 성과가 괜찮은 편인지 알기 어렵습니다.

셋째, 두 캠페인은 함께 쓸 수 있습니다. 구글은 검색어가 검색 캠페인의 일치검색 키워드와 같을 때는 검색 캠페인이 실적 최대화 캠페인보다 먼저 게재된다고 안내합니다. 상호명이나 핵심 상품명처럼 꼭 직접 관리하고 싶은 검색어는 검색 캠페인에 일치검색으로 두고, 그 밖의 넓은 기회는 실적 최대화 캠페인에 맡기는 식으로 나눌 수 있습니다.

실적 최대화 캠페인을 더할 때 무엇을 준비하나요?

  1. 전환 목표 점검: 문의 · 구매가 한 번씩만 세어지는지 직접 넣어 확인합니다.
  2. 재료 준비: 문구, 가로형 · 정사각형 이미지, 로고, 가능하면 짧은 영상을 준비합니다.
  3. 잠재고객 신호: 기존 고객 목록이나 관심사처럼 어떤 사람을 찾는지 힌트를 줍니다. 대상을 제한하는 설정이 아니라 학습을 돕는 힌트입니다.
  4. 예산 따로 두기: 검색 캠페인 예산을 빼서 쓰기보다, 시험할 금액을 따로 정합니다. 그래야 새 캠페인 때문에 잘 되던 검색 캠페인이 흔들리지 않습니다.

이미지와 문구 준비는 반응형 디스플레이 광고 재료 글의 원리와 비슷합니다. 세부 기준은 바뀔 수 있으니 진행 전에 구글의 최신 안내를 확인하세요.

자주 하는 실수는 무엇인가요?

  • 전환 추적 없이 실적 최대화 캠페인 열기: 기준이 없어 예산이 빠르게 나갑니다.
  • 재료를 최소한만 넣기: 이미지 · 영상이 부족하면 보일 수 있는 자리가 줄어듭니다.
  • 검색 캠페인을 바로 끄기: 직접 관리하던 핵심 검색어까지 맡기게 됩니다.
  • 며칠 만에 판단하기: 학습이 자리 잡을 시간을 두고 결과를 봅니다.

유어팀은 캠페인 순서를 어떻게 정하나요?

유어팀은 전환 추적 상태와 가게가 가진 사진 · 영상을 먼저 확인하고, 검색 캠페인으로 기록을 모은 뒤 실적 최대화 캠페인을 더할지 함께 정합니다. 시작 전에는 모든 비용이 적힌 견적서를 드립니다. 자세한 내용은 구글 광고 페이지를 보시고, 상담 신청으로 문의해 주세요.
