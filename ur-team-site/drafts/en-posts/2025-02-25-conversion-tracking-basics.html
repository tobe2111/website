Conversion tracking records whether a person who saw your ad went on to inquire, call or buy. The counting point differs by action. An inquiry is counted at the submission confirmation page, a call by the number of taps on the call button, and a purchase at the payment confirmation page. Each is recorded together with the ad the person came from.

Key takeaways

  • Unlike clicks, a conversion (the action the advertiser wants actually taking place) is only recorded if you set it up.
  • Inquiries, calls and purchases are counted at different points, so define them one by one.
  • Taps on a call button are not the same as actual calls. Check them against your call log.
  • After setup, submit a test inquiry and a test order yourself and confirm that each one is counted exactly once.

What do you miss without conversion tracking?

By default, an ad console shows only impressions and clicks. What a person did after clicking is recorded only if your website reports it.

Say keyword A gets 1 inquiry from 100 clicks, and keyword B gets 5 inquiries from 30 clicks. Without conversion tracking, the screen shows only clicks, so A looks like the one doing the work. Budget shifts to A, and B, which was producing the inquiries, shrinks. Metrics such as click-through rate and conversion rate only mean something once you have conversion counts. How do you count inquiries, calls and purchases?

ActionCounting pointWatch out for
Inquiry formNumber of times the submission confirmation page opensIf you count presses of the "Send" button, you include submissions that failed because of input errors
Phone callNumber of taps on the call button on a mobile screenTaps followed by an immediate hang-up are mixed in, and calls made after seeing the number on a PC are left out
Messenger and bookingNumber of taps on the chat button, number of completed bookingsWhat happens after the visitor moves to an outside service has to be checked separately in that service's statistics
PurchasePayment confirmation page, together with the order amountRefreshing the confirmation page can count the order twice, and cancellations and refunds must be subtracted separately

Actions that end outside your website have to be recorded by a person. Ask phone and walk-in customers "How did you hear about us?" and keep the answer as one column in your intake log. It may look like a chore, but it is often the only way to match the numbers on the screen with actual customer counts.

Also decide how many times to count when the same person repeats the same action. The conversion settings of ad platforms usually offer two options: count every time the action happens, or count only once per ad click. Google Ads calls these "Every" and "One", and you can choose separately for each type of conversion. For purchases, each one brings revenue, so the first option fits. For inquiries, one person sending the form twice is still one customer, so the second fits. When you count every purchase, set tracking up to pass the order number as well. Then the same order is not counted twice even if the confirmation page is refreshed, because an order number that comes in again is treated as a duplicate and not counted. On the other hand, if the order number field is built so that it always carries the same value, only the first order is counted and the rest are dropped. When you test, confirm that a different number is passed for each order.

Another option is to keep a phone number used only for ads. Calls to that number can be treated as coming from the ad, so the call log alone gives you the number of calls and their length. Google Ads splits call conversions three ways: calls made directly from an ad, calls to a phone number shown on your website, and taps on a phone number on your mobile website. Read reports with care for whether a figure is calls or taps.

How do you record which ad a visitor came from?

There are two main ways, and they are usually used together.

  • The ad platform's conversion tracking feature: put the short piece of code the platform gives you on your website, and conversions by people who clicked that platform's ads show up in the ad console by keyword and by ad creative.
  • An analytics tool and tags: add tags that state the traffic source (UTM parameters) to the end of your ad links, and a web analytics tool lets you compare different routes, such as search ads, blogs and text messages, on one screen.

Keep in mind that each platform counts by its own rules. If one person sees ads on two platforms in turn and then inquires, both platforms may count it as their own result. So the sum of conversions across platforms often comes out higher than the actual number of inquiries received. The benchmark is always the actual number received. The names of settings menus and how they work can change, so check each platform's latest guidance before you start.

In what order should you set it up the first time?

  1. Choose one or two conversions. Pick the actions closest to revenue. For a consultation-based business, that is form inquiries and calls. For an online store, it is completed payment.
  2. Create a confirmation page. If the form only shows a message in the same place after it is sent, change it so that it moves to a "Your inquiry has been received" page with its own address.
  3. Install the code. If this is hard to do yourself, pass the platform's installation guide to whoever built your website.
  4. Tag your ad links. Set naming rules at the start so the data can be grouped into tables later. Tags usually fill in three fields together: where the visit came from (source), what kind of route it is (medium), and which campaign. If even one field is empty, the visit is lumped under "(not set)" in the analytics screen. Analytics tools read uppercase and lowercase letters as different values, so use lowercase throughout, with no spaces.
  5. Test it yourself. Click an ad, submit an inquiry and tap the call button. Check whether one action is counted twice or not counted at all.
  6. Match against actual inquiries received. Once a week, put the conversion count on the screen next to the count in your log.

Common mistakes

  • Treating button presses as the number of inquiries. Pressed and received are not the same thing.
  • Adding scrolls and time on page as conversions, so only the numbers grow. Keep actions far from revenue as reference metrics.
  • Mixing in visits from staff and the agency. Mark test inquiries and exclude them.
  • Finding out weeks later that the code went missing after a website update. Test again on the day of any redesign.
  • Blaming the ads when the landing page is what blocks inquiries. If clicks are high and conversions are absent, also see seven common landing page mistakes that waste ad spend.
