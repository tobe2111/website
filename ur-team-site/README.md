# 유어팀 통합 홈페이지 (ur-team.com)

아임웹(마케팅)과 프레이머(유통 · 수출)로 따로 있던 두 홈페이지를 한 사이트로 합친 것입니다.
서버 · 데이터베이스 없이 HTML 파일 묶음으로 뜨므로 유지비가 들지 않습니다. 외부 라이브러리도 쓰지 않습니다.

```bash
node ur-team-site/build.mjs     # 사이트 만들기 → ur-team-site/dist/
node ur-team-site/check.mjs     # 링크 · 사진 · 예전 주소가 다 이어지는지 검사
```

`ur-team-site/` 아래를 고쳐 올리면 GitHub 이 위 두 가지를 자동으로 돌리고(`.github/workflows/ur-team-site.yml`),
완성본을 Actions 화면의 '결과물(ur-team-site)'로 올려 둡니다. 내려받아 열어 보면 됩니다.

## 폴더

| 폴더 · 파일 | 무엇 |
| --- | --- |
| `site.json` | 회사 정보(전화 · 이메일 · 카카오톡), 상담 신청 연결, 예전 주소 → 새 주소 표 |
| `src/pages/` | 페이지 한 장 = 파일 하나. `marketing/hospital.html` → `/marketing/hospital/` |
| `src/posts/` | 블로그 글 한 편 = 파일 하나 |
| `src/partials/` | 모든 페이지가 같이 쓰는 칸(머리말 · 꼬리말 · 팀 소개 · 상담 안내) |
| `assets/` | 디자인(CSS) · 움직임(JS) · 사진 · 영상 |
| `source/` | 옛 사이트 원본(로그인 정보 지운 것) · 공식 로고 원본 · 사진 출처 목록 |
| `tools/gen_products.py` | 마케팅 상품 8개 페이지를 아임웹 원본 순서대로 처음 만들 때 쓴 도구 |

페이지에서 `<!--@ team -->` 처럼 적으면 `src/partials/team.html` 이 그 자리에 들어갑니다.

## 블로그 글 올리기

`src/posts/` 에 파일 하나를 만듭니다. 파일 이름이 주소가 됩니다(`2026-12-01-china.html` → `/blog/2026-12-01-china/`).

```html
<!-- {"title": "글 제목", "date": "2026-12-01", "category": "마케팅", "summary": "목록에 보일 한 줄", "cover": "/assets/img/…"} -->
<p>본문 첫 문단</p>
<h2>소제목</h2>
<p>…</p>
```

- 최신 날짜가 목록 맨 위에 옵니다.
- 날짜가 오늘보다 뒤인 글은 그날이 오기 전까지 사이트에 나오지 않습니다(예약 글).
- 사진은 `assets/img/` 에 넣고 `/assets/img/파일이름` 으로 적습니다.

## 상담 신청 켜기

지금은 신청서가 "온라인 접수 준비 중"으로 떠 있고, 카카오톡 · 전화로 안내합니다. 이렇게 켭니다:

1. 상인회 엔진에서 유어팀 조직의 **랜딩 편집 → 바깥 홈페이지 주소**에 `https://ur-team.com` 을 등록합니다.
   (등록 안 된 주소에서 온 신청은 엔진이 받지 않습니다.)
2. `site.json` 의 `form.endpoint` 에 `https://<엔진 주소>/lead-in/<조직 주소>` 를 적습니다.
3. 엔진에 봇 방지(Turnstile)가 켜져 있으면 `form.turnstileSiteKey` 도 적고,
   Cloudflare 에서 그 사이트 키에 `ur-team.com` 을 허용합니다.

신청서의 칸이 엔진의 어디로 들어가는지:

| 신청서 | 엔진 상담 DB |
| --- | --- |
| 업체명 · 담당자 | 이름 |
| 연락처 · 이메일 · 월 광고 예산 · 상담 신청 경로 | 같은 이름의 칸 |
| 관심 분야 · 회사 URL · 희망 채널 · 문제점 · 강점 · 문의 내용 | 상담 내용 한 칸에 `[관심 분야] …` 처럼 묶어서 |
| 광고 링크의 utm, 들어오기 전 페이지 | 유입 경로 |

## ur-team.com 에 올리기

`dist/` 폴더가 완성본입니다. 정적 파일을 올릴 수 있는 곳이면 어디든 됩니다.
Cloudflare Pages 를 쓰면 `dist/_redirects` 를 읽어 예전 주소(`/hospital`, `/product-3`, `/kr/export` …)를
새 주소로 영구 이동(301)시킵니다. 다른 곳에 올려도 예전 주소마다 이동 페이지가 들어 있어서 링크가 끊기지 않습니다.

- 빌드 명령: `node ur-team-site/build.mjs` · 결과 폴더: `ur-team-site/dist`
- 도메인을 옮기기 전에 프레이머 · 아임웹 구독을 먼저 끊지 마세요. 새 사이트가 뜬 것을 확인한 뒤에 끊습니다.

## 알아둘 한계

- 마케팅 상품 8개 페이지의 설명 그림은 아임웹 원본 그림을 그대로 옮긴 것입니다. 그림 속에 예전 로고 무늬와 전화 · 카톡 배너가 남아 있습니다.
- 회사소개서 다운로드 버튼은 PDF 파일을 받으면 붙입니다.
- 영어 페이지는 아직 없습니다. 예전 영어 주소(`/en/…`)는 한국어 페이지로 이어집니다.
