# 유어팀 블로그 자동 작성 지침

매주 화 · 금요일에 자동으로 도는 작업(예약 작업)이 이 문서를 읽고 블로그 글을 씁니다.
사람이 글을 쓸 때도 같은 기준을 씁니다. 기준을 바꾸고 싶으면 이 파일을 고치면 됩니다.

## 한 번에 하는 일

1. 저장소 `tobe2111/website` 의 라이브 갈래 `claude/awesome-faraday-oj6c93` 를 최신으로 받는다.
2. `ur-team-site/src/posts/` 의 기존 글 제목을 모두 훑어, **겹치지 않는 새 주제**를 고른다.
   - 화요일: 1~2편, 금요일: 1편 (한 주에 2~3편). 몇 편을 쓸지는 그 회차에 쓸 만한 주제가 얼마나 있는지로 정한다.
   - 주제 비중: **광고(네이버 검색광고 · 파워링크 · 당근 광고 · 메타/인스타그램 광고 · 구글 광고)와 병원 마케팅이 절반**, **3D프린팅이 셋 중 하나**(화요일에 2편을 쓰면 그중 1편은 3D프린팅), 나머지는 유통 · 수출 · 일반 마케팅.
   - 3D프린팅 글은 구글 검색에서 사람들이 실제로 치는 말(예: 'STL 파일', '3D프린팅 비용', 'PLA PETG 차이', '3D프린터 출력 대행')이 제목 앞쪽에 오게 씁니다. 전문가가 쓴 글답게, 원리와 함께 실제로 맡길 때 무엇을 정해야 하는지를 구체적으로 씁니다.
   - 같은 플랫폼 글이 이미 많으므로 제목이 말하는 **한 가지**만 깊게 다룬다. 최근 4주 안에 나온 글과 같은 플랫폼 · 같은 각도는 피한다.
3. 아래 '글의 형식'과 '사실 규칙'대로 글을 쓴다. 파일 이름은 `YYYY-MM-DD-영문-슬러그.html`, 날짜는 글을 쓰는 날(한국 시간).
4. 표지를 만든다. 아래 모양의 JSON 파일을 임시 폴더에 만들고 도구를 돌린다.
   ```bash
   # [{"slug": "영문-슬러그", "title": "글 제목", "category": "분류", "icon": "chart"}]
   node ur-team-site/tools/blog-cover.mjs <목록.json>
   ```
   `icon` 은 doc · check · chart · search · split · pin · chat · calendar · coins · pen · box · image · target · video · globe · filter · cart 중 주제에 맞는 것.
   글 첫 줄의 `cover` 는 `/assets/img/blog/<슬러그>-cover.webp`.
5. 공유 그림과 사이트를 만들고 검사한다. **검사가 실패하면 올리지 않는다.**
   ```bash
   node ur-team-site/build.mjs && node ur-team-site/tools/og.mjs && node ur-team-site/build.mjs
   node ur-team-site/check.mjs
   ```
6. 자기 점검(아래 목록)을 글마다 실제로 한다.
7. 작업 갈래에 올리고, 라이브 갈래(`claude/awesome-faraday-oj6c93`)로 가는 검토 요청을 만들어 합친다.
   합친 뒤 `https://ur-team.com/blog/<파일이름에서 .html 뺀 것>/` 이 열리는지 확인한다.
8. 무엇을 썼는지 한국어로 짧게 보고한다(제목, 주소, 확인이 필요해 보이는 대목).

하나라도 막히면(검사 실패, 합치기 충돌, 쓸 만한 주제 없음) 억지로 올리지 않고, 무엇이 막혔는지 보고하고 끝낸다.

## 글의 형식

첫 줄은 한 줄짜리 주석이고 안은 올바른 JSON 이다.

```
<!-- {"title": "글 제목", "date": "YYYY-MM-DD", "category": "네이버 광고", "summary": "두 문장, 80~120자.", "cover": "/assets/img/blog/슬러그-cover.webp"} -->
```

- 분류(블로그의 주제 버튼)는 다음 아홉 가지 중 하나: `네이버 광고` · `구글 · 인스타그램 광고` · `당근 · 지역 마케팅` · `블로그 · 콘텐츠` · `마케팅 전략 · 성과` · `병원 마케팅` · `국내 유통` · `해외 수출` · `3D프린팅`. 글자 하나까지 똑같이 적는다(다르게 적으면 새 버튼이 생긴다).
- summary 안에 큰따옴표(")를 쓰지 않는다.
- 둘째 줄부터 본문. 쓸 수 있는 태그: `p, h2, h3, ul, ol, li, strong, a, table(thead/tbody/tr/th/td), blockquote`. `<h1>`, `<img>`, `<script>`, 인라인 style 은 쓰지 않는다.

구조:

1. **첫 문단이 곧 답이다.** 제목의 질문에 2~3문장으로 바로 답한다.
2. `<p><strong>핵심 요약</strong></p>` 다음에 `<ul>` 3~4줄.
3. `<h2>` 5~6개. 독자가 검색할 만한 질문형으로.
4. 표 1개나 번호 목록 1개 이상(비교 · 순서 · 점검표).
5. 끝에서 두 번째 `<h2>` 는 점검표나 "자주 하는 실수".
6. 마지막 `<h2>` 는 유어팀이 이 주제에서 하는 일 2~3문장 + 관련 페이지 링크 + `<a href="/contact/">상담 신청</a>`.

분량: 태그와 공백을 뺀 본문 1,900~3,000자.

어조: 존댓말, 짧은 문장. 전문 용어는 처음 나올 때 풀어 쓴다. 구체적으로 쓴다.
쓰지 않는 것: 긴 줄표, 느낌표, 이모지, "~의 시대", "결론적으로", "알아보겠습니다", "무조건", "100%", 그리고 유어팀이나 방법의 효과에 붙는 "보장 · 최고 · 1위 · 유일".

## 사실 규칙 (가장 중요)

- **지어내지 않는다.** 통계 · 조사 결과 · 사례 · 고객사 이름 · 가격을 만들지 않는다. 숫자 예시는 "예를 들어"라고 밝힌 가상의 계산으로만 든다.
- **자주 바뀌는 것은 원리로 쓴다.** 최소 입찰가, 수수료율, 메뉴 이름, 정책 세부는 단정하지 않고 "세부 기준은 바뀔 수 있으니 진행 전에 각 플랫폼 · 기관의 최신 안내를 확인하세요"를 한 번 적는다.
- **법 · 규정 주제**(의료광고, 표시광고, 개인정보, 수출 인증)는 일반 원칙만 쓰고 조문 번호 · 과태료 액수를 단정하지 않는다. "일반적인 안내이며, 실제 적용은 관계 기관이나 전문가에게 확인하세요"를 한 번 넣는다. 병원 글에 치료 효과 · 의학 정보를 쓰지 않는다.
- **자료를 찾아 확인한다.** 검색과 원문 열람이 되면 공식 자료(네이버 광고 도움말, 구글 광고 고객센터, 메타 비즈니스 지원 센터, 당근 비즈니스 도움말, 법령정보센터, 공정거래위원회, 보건복지부, KOTRA, 관세청 등)를 열어 대조한다. 대행사 블로그는 단서로만 읽는다.
  - **직접 열어 확인한 공식 자료**가 있으면 글 맨 끝에 붙인다. 열지 못한 주소는 넣지 않는다.
    ```
    <h2>참고한 자료</h2>
    <ul class="sources">
      <li><a href="https://…" target="_blank" rel="noopener nofollow">기관 · 서비스 이름, 문서 제목</a></li>
    </ul>
    ```
- **유어팀에 대해 말할 수 있는 사실은 아래뿐이다.**
  - 국내 유통: 직접 사입, 공동구매, 라이브커머스, 폐쇄몰, B2B 납품. 오픈마켓 판매는 하지 않고 가격 질서를 지킨다. 정산 · 판매 데이터를 공유한다.
  - 해외 수출: 미국 · 인도 · 중국 · 동남아 · 중동 · 일본 · 유럽 7개 권역. 바이어 발굴부터 물류 · 결제 · 규제, 현지 B2C 판매까지 돕는다.
  - 마케팅: 네이버 광고, 구글 광고, 메타(인스타그램 · 페이스북) 광고, 블로그, 당근마켓, 맘카페, 플레이스 · 리뷰, 체험단, 언론 9가지 상품. 병원 마케팅과 해외 환자 유치는 전담으로 따로 운영하고, 같은 진료과 · 같은 지역구의 경쟁 병원은 맡지 않는다.
  - 3D프린팅(출처: `/3d-printing/` 페이지): FDM · SLA 장비 41대 운용(대형은 Z18 305×305×457mm, 복합 소재는 Bambu, 정밀 표면은 SLA XFAB-DWS Ø180×180mm). 3D 모델링, 보유 파일 출력, 소량 · 대량 생산, 강의 · 출강. 견적은 출력 시간이 아니라 사용 재료의 무게(g)로 산정, 3D프린팅은 5,000원부터 · 작업일 2일부터, 모델링+프린팅은 80,000원부터 · 작업일 4일부터(수정 2회 포함). 통상 3~7일 출고, 출고 전 완성품 사진 확인, 수량 1개부터. 재료는 PLA · ABS · 레진 · 카본/유리섬유 강화 소재. 설계 기준으로 최소 벽 두께 1.5~2mm, 45° 넘는 오버행은 서포트, 조립 공차 0.5mm 안팎을 안내한다(장비 · 재료에 따라 다름). **후가공(표면 연마 · 도색)은 하지 않는다.** 접수 파일 STL · STEP · OBJ · 3MF. 거래가 끝난 작업 파일은 2시간 안에 파기, 제작물 저작권은 의뢰인에게. 자체 브랜드: 온등(한국 전통 조명 52종), 아득(공룡 화석 조립 모형 15종). 무료 도구: 3D 파일 변환기(`/3d-converter/`), 3D 뷰어(`/3d-viewer/`).
  - 3D프린팅 글의 마지막에서는 유어팀이 모델링부터 출력까지 맡는다는 것과 견적 기준(재료 무게)을 쓰고 `/3d-printing/`, 글과 맞으면 `/3d-converter/` · `/3d-viewer/`, 그리고 `/contact/` 로 잇는다. 장비 대수 · 가격은 위에 적힌 것만 쓴다.
  - 메타 광고 글의 마지막에서는 "유어팀은 메타(인스타그램 · 페이스북) 광고를 대행합니다"라고 쓰고 `/marketing/meta/` 와 `/contact/` 로 잇는다. 가격 · 실적은 쓰지 않는다.
  - 일하는 방식: 상담은 무료. 시작 전에 모든 비용이 적힌 견적서를 준다. 3개월 계약 뒤 연장. 대표와 실무자가 함께 있는 카톡방과 정기 보고서로 소통한다. 목표는 고객사의 순수익이다.

## 자기 점검 (글마다)

- 첫 줄 JSON 이 올바르게 읽히는가
- 기존 글과 제목 · 각도가 겹치지 않는가
- 첫 문단이 답으로 시작하는가, 핵심 요약 · 표나 번호 목록 · 상담 신청 링크가 있는가
- 분량이 범위 안인가
- 지어낸 숫자 · 사례, 과장 표현, 유어팀 사실 범위를 넘는 문장이 없는가
- 링크가 모두 실제로 있는 주소인가
- `node ur-team-site/check.mjs` 가 통과하는가

## 영어판

자동 작성은 한국어 글만 씁니다. 영어판(`src/en/posts/`)은 만들지 않습니다.
