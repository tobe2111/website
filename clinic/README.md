# 병원 홈페이지 빌더

병원 한 곳 = `sites/<병원>/` 폴더 하나. 원고(JSON)를 넣고 빌드하면 완성된 웹페이지 묶음이 나옵니다.
서버·데이터베이스가 없어서 유지비가 들지 않고, 고장 날 곳도 없습니다.

```bash
node clinic/build.mjs cheonsaem      # → clinic/dist/cheonsaem/
node --test clinic/test/*.test.mjs   # 검사
```

## 병원 하나 추가하기

1. `sites/cheonsaem/`을 복사해서 새 이름을 붙입니다. 예: `sites/hanbit/`
2. 아래 세 파일을 고칩니다.
   - `site.json`: 병원 정보, 진료 시간, 의료진, 색(`theme.accent`), 첫 화면 배치(`theme.hero`: `split` 또는 `full`)
   - `treatments.json`: 진료 페이지. 증상 → 원인 → 진단 → 치료 → 회복 → 자주 묻는 질문 순서로 씁니다.
   - `notices.json`: 공지사항
3. 사진은 `sites/<병원>/media/`에 넣고, 원고에는 `"src": "/media/파일이름.jpg"`로 적습니다.
   - 사진 크기는 콘텐츠 규격표를 따릅니다.
   - 사진이 없는 칸에는 규격이 적힌 빈 칸이 대신 보입니다.

## 빌드가 대신 지켜주는 것

- **의료광고 금지 표현**: 원고에 "최고·완치·후기·전후 사진·할인" 같은 말이 있으면 빌드가 멈추고, 어느 칸인지 알려줍니다. (`lib/adlint.mjs`)
- **공개 전에 채울 자리**: `【확인 필요】`, `○○`, `000-0000` 같은 자리 표시가 남아 있으면 빌드할 때 목록으로 보여줍니다.
- **검색 노출**: 페이지마다 다음을 자동으로 넣습니다.
  - 제목, 설명, 대표 주소, 공유 썸네일 정보
  - 검색엔진용 병원 정보: 병원, 의료진, 진료 시간, 진료 페이지, 자주 묻는 질문
  - 사이트 지도(`sitemap.xml`)와 크롤러 안내(`robots.txt`)
- **AI 검색**: 병원 요약 안내문(`llms.txt`)을 자동으로 만듭니다.

## 아직 안 되는 것 (정직한 한계)

- **온라인 상담 접수**: `site.json`의 `form.endpoint`가 비어 있으면 신청 단추가 잠기고 전화 예약으로 안내합니다. 접수를 받을 곳은 따로 연결해야 합니다.
- **지도**: 네이버·카카오 지도로 넘어가는 링크만 있습니다. 화면 안에 넣는 지도는 주소가 확정된 뒤에 붙입니다.
- **사진 자동 압축**: 받은 사진을 그대로 씁니다. 올리기 전에 규격표 크기로 맞춰 주세요.
