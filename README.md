# 서초구 상인회 웹사이트

서초구 지역 상인회를 위한 반응형(Responsive) 공식 웹사이트입니다. 별도의 빌드 과정이나 서버 없이 브라우저에서 바로 열어볼 수 있는 정적(static) 사이트로 제작되었습니다.

## 주요 특징

- **완전 반응형** — 모바일 · 태블릿 · 데스크톱 모든 화면에 최적화 (모바일 햄버거 메뉴 포함)
- **접근성 고려** — 시맨틱 마크업, 키보드 포커스 스타일, `본문 바로가기`, `prefers-reduced-motion` 대응
- **가벼운 구성** — 외부 프레임워크 없이 순수 HTML/CSS/JS. 폰트만 Google Fonts(Noto Sans KR) 사용
- **부드러운 인터랙션** — 스크롤 등장 애니메이션, 통계 카운터, 스크롤 스파이 내비게이션, 맨 위로 버튼

## 구성 섹션

| 섹션 | 내용 |
| --- | --- |
| 홈 (Hero) | 상인회 소개 및 핵심 통계 |
| 상인회 소개 | 상생 협력 · 권익 대변 · 교육 지원 · 지역 행사 |
| 공지사항 | 최신 소식 목록 |
| 상권 안내 | 서초 지역 시장 · 상점가 소개 |
| 행사·이벤트 | 다가오는 행사 일정 |
| 회원 혜택 | 회원 혜택 및 회비 안내 |
| 오시는 길 | 위치 · 연락처 · 문의 폼 |

## 파일 구조

```
website/
├── index.html        # 페이지 마크업
├── css/style.css     # 스타일 및 반응형 규칙
├── js/main.js        # 인터랙션 (내비게이션, 애니메이션, 폼)
└── assets/           # 이미지 등 정적 자원
```

## 실행 방법

`index.html` 파일을 브라우저에서 열면 됩니다. 로컬 서버로 확인하려면:

```bash
# Python 3
python3 -m http.server 8000
# 이후 http://localhost:8000 접속
```

## 커스터마이징 안내

- **연락처 / 주소 / 이메일**: `index.html`의 `#contact`, 푸터 영역에서 실제 정보로 교체하세요.
- **공지·행사·상권 내용**: 현재는 예시 데이터입니다. 실제 내용으로 업데이트하세요.
- **색상 테마**: `css/style.css` 상단 `:root` 변수(`--green-700` 등)를 조정하면 전체 색감이 바뀝니다.
- **문의 폼**: 현재는 클라이언트 측 데모입니다. 실제 접수는 이메일 서비스(Formspree 등)나 백엔드 연동이 필요합니다.
