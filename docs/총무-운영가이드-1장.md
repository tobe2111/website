# 상인회 홈페이지 — 총무님 운영 가이드 (1장)

> 이 한 장이면 충분합니다. 어려우면 아래 **문의처**로 연락 주세요.
> CS는 **총무님 → 저희** 한 경로로만 흐릅니다. 사장님들 문의는 총무님이 1차로 받아 주세요.

---

## 0. 로그인
- 주소: **우리 상인회 홈페이지 주소 + `/login`**
- 처음 받은 **관리자 이메일 / 임시 비밀번호**로 로그인 → 즉시 **비밀번호 변경**(우측 상단 계정).
- 보안을 위해 **2단계 인증(2FA)** 설정을 권장합니다. (관리자 화면 안내대로 1분)

---

## 1. 제일 먼저 할 일 3가지
1. **상인회 정보·브랜딩** 저장 — 이름·한 줄 소개·대표 전화·주소, 그리고 **대표 색상 1개**만 고르면 사이트 전체 색이 바뀝니다. 로고가 있으면 올려 주세요.
2. **홈페이지 구성 편집** — 필요 없는 섹션은 끄고, 순서(▲▼)와 문구를 직접 바꿉니다.
3. **첫 공지 1건** 올리기 — "홈페이지 열었습니다" 같은 짧은 글이면 됩니다.

---

## 2. 사장님(회원) 늘리는 법 — 두 가지
### (A) 사장님이 직접 가입 — **가장 좋은 방법**
- 사장님께 **홈페이지 주소 + `/register`** 를 문자로 보내세요.
- 사장님이 직접 업체명·사진·영업시간을 채웁니다. → **살아있는 홈**이 됩니다.

### (B) 총무님이 대신 등록 — **사장님이 직접 못 하실 때만**
- 관리자 화면 → **회원 관리 → "사장님 대신 등록하기(대행)"** 열기
- 성함·이메일·업체명 입력 → **임시 비밀번호**가 나옵니다 → 사장님께 전달.
- ※ 대행 등록은 "대행"으로 집계됩니다. 되도록 **(A) 직접 가입**을 권해 주세요.

---

## 3. 매일/매주 하는 일 (5분)
- **승인 대기** 업체가 있으면 확인 후 **승인**. (관리자 화면 상단에 개수 표시)
- 새 **공지·행사** 올리기. 사진 1장이면 훨씬 보기 좋습니다.
- **알림함** 확인 — 새 가입·서명 요청이 여기에 쌓입니다.

---

## 4. 계약·동의서 받기 (전자서명)
- 관리자 화면 → **전자서명 문서** → 문서 작성 → 서명할 회원 선택.
- **순차 서명**(정해진 순서대로) / 동시 서명 중 선택, 마감 기한 설정 가능.
- 완료되면 **증명서(PDF)**를 인쇄·저장할 수 있습니다. (위·변조 검증 포함)

---

## 5. 참여 계측 (숫자 3개만 봐 주세요)
관리자 화면의 **참여 계측** 칸에 세 숫자가 있습니다.
- **셀프 등록률** — 사장님이 직접 가입한 비율. **높을수록 좋음.**
- **정보 채움률** — 소개·사진이 있는 업체 비율.
- **최근 30일 갱신률** — 홈이 방치되지 않고 살아있는지.

> 저희가 이 세 숫자를 보고 다음 개선을 결정합니다. 특별히 뭘 하실 필요는 없고, **(A) 직접 가입을 권하는 것**만으로 셀프 등록률이 올라갑니다.

---

## 6. 자주 묻는 것
- **사장님이 비밀번호를 잊었어요** → 회원 관리에서 **임시 비밀번호** 재발급 → 전달.
- **사진이 안 올라가요** → 용량이 큰 사진은 자동으로 줄여 올립니다. 그래도 안 되면 문의처로.
- **주소를 우리 도메인으로 바꾸고 싶어요** → 저희에게 요청하세요. (개별 도메인 연결 지원)
