# 모집 사이트 운영 매뉴얼

가맹점·수강생·회원을 모으는 사이트를 맡은 담당자용입니다.
컴퓨터를 잘 몰라도 됩니다. **화면에서 눌러야 할 곳만** 적었습니다.

---

## 0. 로그인

1. 사이트 주소 뒤에 `/login` 을 붙여 들어갑니다.
2. 발급받은 이메일·비밀번호를 넣습니다.
3. 들어오면 오른쪽 위에 **상담 DB**, **관리자** 메뉴가 생깁니다.

> 비밀번호를 잊었으면 `/forgot` 에서 재발급을 요청하세요.

---

## 1. 매일 하는 일 — 상담 신청 처리

**상담 DB** 화면(`/admin/leads`)이 전부입니다.

1. **신규**로 표시된 건에 전화합니다. 연락처를 누르면 바로 걸립니다.
2. 통화 후 **상태**를 바꿉니다.

| 상태 | 언제 |
| --- | --- |
| 신규 | 아직 연락 안 함 |
| 연락 완료 | 통화는 했고 결정 전 |
| 상담·방문 | 방문 상담까지 진행 |
| 계약 | 성사됨 |
| 보류·종료 | 지금은 아님 |

3. **메모**에 통화 내용을 한 줄 남깁니다("3/2 통화, 4월 오픈 희망").
4. 계약으로 가면 **계약서 만들기**를 누릅니다 — 이름·연락처가 자동으로 따라가
   서명 링크까지 이어집니다.

> **왜 상태를 남겨야 하나요?** 담당자가 여러 명이면 누가 어디까지 했는지 알 수 없습니다.
> 상태만 제때 바꿔도 같은 사람에게 두 번 전화하는 일이 없어집니다.

### 숫자 읽는 법

화면 위쪽 카드가 이번 성적표입니다.

- **미처리(신규)** — 오늘 처리할 일. 0으로 만드는 게 목표입니다.
- **30일 전환율** — 랜딩에 온 사람 중 몇 %가 신청했는지. **2~5%면 보통**입니다.
  1% 아래로 떨어지면 화면 문구나 광고 타겟을 손봐야 합니다.
- **광고 출처** — 어느 광고가 실제로 신청을 만들었는지. 여기서 0건인 광고는 끊으세요.

---

## 2. 광고 링크 만들기 (중요)

광고에 그냥 주소를 넣으면 **어디서 왔는지 알 수 없습니다.** 뒤에 꼬리표를 붙이세요.

```
https://우리주소.kr/t/우리사이트/?utm_source=naver&utm_medium=cpc&utm_campaign=봄모집
                                    ↑ 어디에         ↑ 무슨 광고    ↑ 어떤 캠페인
```

| 붙이는 곳 | `utm_source` 예시 |
| --- | --- |
| 네이버 검색광고 | `naver` |
| 인스타그램 | `instagram` |
| 당근·지역카페 | `karrot`, `cafe` |
| 전단지 QR | `flyer` |

이렇게 보내면 상담 DB의 **광고 출처**에 그대로 쌓입니다.

---

## 3. 화면 문구 고치기

**랜딩 편집**(`/admin/landing`)에서 고칩니다.

1. 각 섹션의 **스위치**로 켜고 끕니다.
2. **▲▼** 로 순서를 바꿉니다.
3. 문구를 고칩니다. `한 줄에 하나`라고 적힌 칸은 **줄바꿈으로 항목을 나누고 `|` 로 칸을 나눕니다.**

```
가맹비 | 1,000만원 | 부가세 별도
교육비 | 300만원 | 2인 기준
```

4. **초안 저장** → **미리보기**로 확인 → **발행하기**.

> ⚠️ **저장만 하면 손님에게는 안 보입니다.** 반드시 **발행하기**까지 눌러야 바뀝니다.
> 잘못 고쳤으면 **초안 버리기**로 발행본으로 되돌립니다.

### 사진 넣기

- 히어로·브랜드 사진: 해당 칸에서 **파일 선택**하면 끝입니다.
- 메뉴처럼 여러 장: **사진 보관함**에 올린 뒤, 나오는 주소를 복사해 붙여 넣습니다.

```
대표 삼겹살 | 12,000원 | /media/abc123.jpg
```

### 비용 표 가리기

비용 섹션의 **"상담 신청 전에는 흐리게 가리기"** 를 켜면 금액이 가려지고
"상담 신청하면 안내" 문구가 뜹니다. 신청률이 올라가는 대신 문의 전화가 늘어납니다.

---

## 4. 광고 소재마다 다른 문구 (선택)

인스타용과 검색광고용 문구를 다르게 하고 싶을 때 **사본**을 만듭니다.

1. 랜딩 편집 → **현재 내용으로 사본 만들기** → 이름·주소 입력(예: `instagram`)
2. 사본 주소(`/t/우리사이트/l/instagram`)를 그 광고에만 씁니다.
3. 상담 DB의 **랜딩별 성과**에서 어느 쪽 전환율이 높은지 비교합니다.

---

## 5. 개인정보 — 꼭 지켜야 할 것

- 상담 DB의 연락처는 **개인정보**입니다. 화면을 캡처해 단톡방에 올리지 마세요.
- **상담이 끝난 건(계약·보류)은 보관 기간이 지나면 자동으로 지워집니다.**
  기간은 랜딩 편집 화면 맨 아래에서 바꿉니다(기본 365일).
- 신청자가 삭제를 요청하면 해당 줄의 **삭제**를 누르세요. 복구되지 않습니다.
- CSV로 내려받은 파일도 개인정보입니다. 다 쓰면 지우세요.

---

## 6. 자주 겪는 일

| 상황 | 이렇게 하세요 |
| --- | --- |
| 고친 문구가 사이트에 안 보임 | **발행하기**를 눌렀는지 확인 |
| 사진이 안 나옴 | 주소가 `https://` 또는 `/media/` 로 시작하는지 확인 |
| 신청이 갑자기 0건 | 광고가 멈췄는지, 링크가 살아 있는지 먼저 확인 |
| 장난 신청이 들어옴 | 그냥 삭제하세요. 봇은 이미 걸러지고 있습니다 |
| 같은 사람이 두 번 신청 | 10분 안의 중복은 자동으로 막힙니다. 그 이상은 직접 삭제 |
| 알림톡이 안 옴 | 운영사에 문의 — 알림톡은 별도 설정과 잔액이 필요합니다 |
